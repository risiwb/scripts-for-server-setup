curl: downloads files from the web.
git: clones your app repos.
python3, python3-venv, python3-pip: run your Python apps in isolated environments.
ufw: firewall, set to allow only SSH.
htop: live view of CPU, memory, and processes.
sqlite3: command-line tool for SQLite databases; Atuin itself doesn't need it, it's for inspecting your apps' or Atuin's data.
ca-certificates: lets curl/apt verify HTTPS sites; usually already installed.
cloudflared: runs your Cloudflare tunnels.
Atuin: command history with folders, exit codes, and search.
